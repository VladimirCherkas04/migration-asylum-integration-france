# Migration, Asylum & Integration Analysis — France

## Project Overview

This portfolio project analyzes synthetic migration, asylum and integration data for France.

The project demonstrates an end-to-end data analytics workflow using SQL, Python and Tableau.

The analysis covers migration activity, employment, asylum cases, regional differences and integration programs.

**Important:** All data in this project is fully synthetic and created for portfolio and educational purposes. It does not represent real individuals, official government statistics, real asylum cases or confidential information.

## Research Questions

- How did migration activity change over time?
- Which countries of origin were most represented?
- How does employment vary across French regions?
- How is employment associated with education level?
- How does employment vary across age groups?
- What is the distribution of asylum case decisions?
- How does asylum acceptance vary across regions?
- Which citizenship groups are most represented among asylum cases?
- How do integration programs differ in completion and employment outcomes?

## Methodology

The project follows this workflow:

Synthetic CSV data → PostgreSQL → SQL analysis → Python analysis → Tableau dashboards

### SQL

SQL was used for data aggregation, filtering, regional comparisons, employment analysis, asylum analysis and multi-dimensional analysis.

The project contains 12 analytical SQL queries.

### Python

Python was used for data loading, validation, exploratory analysis, indicator calculation and preparation of datasets for Tableau.

Main library:

- pandas

### Tableau

Tableau was used to create analytical sheets and dashboards covering:

- Migration & Employment
- Asylum
- Integration Programs

## Key Findings

Because the dataset is synthetic, these findings are analytical examples rather than real-world estimates.

### Migration and Employment

The overall synthetic employment rate is **57.6%**.

Employment remained relatively stable between 2022 and 2025.

Regional employment rates ranged from approximately **55.5% to 60.2%**.

### Education and Employment

Employment rates varied substantially by education level.

The highest synthetic employment rates were observed among people with Doctorate and Master's degrees, while lower secondary education had the lowest employment rate.

### Age and Employment

The highest employment rates were observed among the 25–34 and 35–44 age groups.

### Asylum

The synthetic asylum dataset contains **4,000 cases**.

- Accepted: 1,234
- Pending: 1,341
- Rejected: 1,161
- Withdrawn: 264

The overall synthetic acceptance rate is **30.85%**.

### Integration Programs

Five integration programs were analyzed:

- Job placement
- Employer matching
- CV workshop
- Language course
- Skills training

The overall synthetic employment outcome rate was **53.33%**.

## Limitations

This project is designed for portfolio and educational purposes.

- All data is synthetic.
- The results do not represent official French migration or asylum statistics.
- Observed relationships should not be interpreted as causal.
- The dataset is illustrative and was created to demonstrate analytical skills.
