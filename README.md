# Migration, Asylum & Integration Analysis — France
Synthetic data analysis of migration, asylum and integration patterns in France using SQL, Python and Tableau.

## Project Overview

This portfolio project analyzes synthetic migration, asylum and integration data for France.

The project demonstrates practical skills in:
- SQL
- Python
- Tableau
- Data cleaning and validation
- Exploratory data analysis
- Data visualization
- Public policy analytics

The dataset is fully synthetic and does not represent real individuals, organizations or confidential government data.
